<h1 align="center">RM Industries</h1>

<p align="center">
  <strong>Tools for people who like knowing how things work.</strong>
</p>

RM Industries is a home for software, developer tools, and experiments
built around a simple idea: good tools should make complicated things
feel simple without hiding how they work.

We build things that solve problems we actually have — from developer
tooling and automation to the infrastructure that supports them.

## Projects

### Etch

A modern approach to managing development environments and dotfiles.

Etch is built around composable configuration, dependency-aware execution,
and automation that remains understandable to the person using it.

[Explore Etch](https://github.com/rm-industries/etch)

### Forge

An opinionated bootstrap for building modern web projects without rebuilding
the foundation every time.

Forge provides a starting point with sensible tooling, automation, quality
checks, and deployment workflows already in place.

[Explore Forge](https://github.com/rm-industries/forge)

## What we care about

- **Simple over clever.** Complexity should earn its place.
- **Automation with purpose.** Automate repetitive work, not understanding.
- **Good defaults.** Getting started shouldn't require fifty decisions.
- **Own your tools.** Configuration and workflows should remain understandable
  and adaptable.
- **Build for maintainability.** The person maintaining it six months from now
  matters.
